# Password Strength Checker

A simple Python program that checks the basic strength of a password and gives suggestions for improvement.

## What it checks

The program checks whether the password contains:

* At least 8 characters
* Uppercase letters
* Lowercase letters
* Numbers
* Special characters

It then gives a basic strength result: Weak, Medium, or Strong.

## How to run

Make sure Python is installed, then run:

```bash
python password_checker.py
```

Enter a test password when prompted.

Example:

```text
Password Check
------------------------------
Length: 10
Strength: Strong
```
